# title_update/

Optional. Put the Title Update 1 package for Army of Two: The Devil's Cartel here, exactly as
copied from your console's storage, for example:

    Content\0000000000000000\454109AB\000B0000\TU_12K22DB_000001C000000.000000000008B

Only Title Update 1 (version 0.0.1.11, SHA-256
`12a417208649711a53687ea33be0049409b965cae7cd82d9406ed2bd536f5675`) is supported. With the file
here, `build_from_dump.bat` recompiles the updated game code and the game mounts the package as
`UPDATE:` when it starts. Leave the folder empty to build the disc version.

Nothing in this folder is tracked by git or included in a release.
